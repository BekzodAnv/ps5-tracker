Цены на PS5 на OLX.uz

Кнопке нужен ключ GitHub, который умеет только запускать сбор в этом репозитории. Он сохранится в этом браузере и больше нигде.

  1. Открой создание ключа (fine-grained token).
  2. Repository access: Only select repositories → .
  3. Permissions → Repository → Actions: Read and write. Больше ничего не включай.

# Трекер цен PS5 на OLX.uz

Каждый день в 10:00 по Ташкенту GitHub Actions собирает объявления PS5 через JSON API OLX.uz,
чистит мусор, сохраняет историю в этот репозиторий и выкладывает страницу с графиками на GitHub Pages.
Компьютер для этого не нужен.

## Файлы
- `ps5-tracker.ps1`: сбор, история, страница, сводка в Telegram
- `config.ps1`: все настройки (запросы, фильтры, границы цен)
- `report-template.html`: шаблон страницы с графиками и кнопкой «Обновить»
- `.github/workflows/collect.yml`: расписание и публикация
- `data/listings.csv`: вся история (по строке на объявление в день)
- `data/summary.txt`: текст последней сводки
- `docs/index.html`, `docs/status.json`: опубликованная страница

## Кнопка «Обновить»
Запускает сбор вне расписания, через 2–3 минуты страница перезагрузится сама.
При первом нажатии попросит ключ GitHub (fine-grained token) с единственным правом
**Actions: Read and write** только для этого репозитория. Ключ хранится только в браузере, где его ввели.
Без ключа сбор можно запустить на вкладке Actions → «Сбор цен PS5» → Run workflow.

## Telegram
Создай бота у @BotFather, напиши ему что-нибудь, узнай chat_id
(`https://api.telegram.org/bot<ТОКЕН>/getUpdates`, поле `chat.id`), затем добавь в
Settings → Secrets and variables → Actions два секрета: `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`.
Сводка приходит после ежедневного сбора. Кнопка «Обновить» сводку не шлёт.

## Запуск на своём компьютере
```powershell
powershell -ExecutionPolicy Bypass -File .\ps5-tracker.ps1 -NoTelegram    # собрать и пересобрать docs/index.html
powershell -ExecutionPolicy Bypass -File .\ps5-tracker.ps1 -ReportOnly    # только пересобрать страницу
```

## Как считается
- Берутся объявления из категории «Игровые приставки» по запросам из `config.ps1`.
- Отбрасываются: другие консоли, аренда, опт, аксессуары, «куплю», объявления «сразу про несколько моделей», цены вне $200–2000.
- Взломанные консоли не входят в статистику: на старой прошивке GTA 6 не запустится.
- Внутри каждой модели убираются выбросы: дешевле 60% или дороже 170% медианы дня.
- Цены в сумах переводятся в $ по курсу, вычисленному из самих объявлений.

## История «назад» (пунктир на графиках)
OLX не хранит историю цен. Дни до первого запуска восстановлены по дате публикации: объявление считается активным
в день D, если создано не позже D, с текущей ценой. Проданные и удалённые объявления туда не попали,
так что это оценка. Настоящая динамика копится с каждым ежедневным запуском.
